# 89/363/EEC: Commission Decision of 31 May 1989 amending the Commission Decision of 30 January 1985 laying down the codes for the notification of animal diseases

*****

COMMISSION DECISION

of 31 May 1989

amending the Commission decision of 30 January 1985 laying down the codes for the notification of animal diseases

(89/363/EEC)

THE COMMISSION OF THE EUROPEAN COMMUNITIES,

Having regard to the Treaty establishing the European Economic Community,

Having regard to Council Directive 82/894/EEC of 21 December 1982 on the notification of animal diseases within the Community (1), as last amended by Decision 89/162/EEC (2), and in particular Article 5 thereof,

Having regard to Commission Decision 84/90/EEC of 3 February 1984 laying down the codified form for the notification of animal diseases pursuant to Directive 82/894/EEC (3), as last amended by Decision 89/163/EEC (4),

Whereas, by virtue of the amendment to Directive 82/894/EEC, certain additional diseases were added to the list of those compulsorily notifiable within the Community;

Whereas the standard telexes used for the notification of these diseases as laid down in Decision 84/90/EEC were subsequently amended by Decision 89/163/EEC;

Whereas, by decision of 30 January 1985, the Commission has laid down codes for the notification of animal diseases (5), whereas this has made it possible to preserve the confidential nature of the information by using common code numbers;

Whereas it is now necessary to provide codes for the additional diseases and the related data for use with the standard telexes;

Whereas the decision of 30 January 1985 also laid down a code for each Member State; whereas the codes already allocated to Spain and Portugal after their accession to the Community must be confirmed;

Whereas the measures provided for in this Decision are in accordance with the opinion of the Standing Veterinary Committee,

HAS ADOPTED THIS DECISION:

## Article 1

As from 1 September 1989, the decision of 30 January 1985 is hereby amended as follows:

1\. Annexes I, II, III and IV are replaced by Annexes I, II, III and IV to this Decision;

2\. the following is added to Annex V:

1.2.3.4 // // // // // ' // 1 // 1 // Spain // // // // // // // // // // 1 // 2 // Portugal'; // // // //

3\. the following is added to Annex VII:

1.2.3.4 // // // // // ' // 2 // 1 // Vesicular stomatitis // // // // // // // // // // 2 // 2 // Peste des petits ruminants // // // // // // // // // // 2 // 3 // Lumpy skin disease // // // // // // // // // // 2 // 4 // Sheep and goat pox (Capripox) // // // // // // // // // // 2 // 5 // African horse sickness // // // // // // // // // // 2 // 6 // Rift valley fever // // // // // // // // // // 2 // 7 // Infectious haematopoietic necrosis'. // // // //

## Article 2

This Decision is addressed to the Member States.

Done at Brussels, 31 May 1989.
